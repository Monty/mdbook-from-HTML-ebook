# Adventures of Sherlock Holmes — mdBook Edition

This book was generated from the Project Gutenberg edition of [*Adventures of Sherlock Holmes*](https://www.gutenberg.org/ebooks/48320).

It was built using [**mdBook**](https://github.com/rust-lang/mdBook), providing a linked Table of Contents, page navigation, built-in search, and theme options.

## Features

- **Linked Table of Contents** with page numbers for chapters and illustrations  
- **Sidebar Chapter List** for quick navigation
- **Search** across the entire text  
- **Theme options** (Light, Rust, Navy, Coal, Ayu)  

## Navigation

You can reach any chapter using the page links in the Table of Contents or by selecting a chapter from the sidebar.
